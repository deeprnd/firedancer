# M1: Safe Money Decisions

## Description

M1 proves the first consumer-money loop for investing:

```text
invest -> see impact
```

The user can turn an investment thesis into a basket, trade ticket,
affordability result, and paper trade. The user then sees how those proposals
affect cash, buying power, portfolio exposure, pending obligations, approval
state, and drift.

## Included Epics

Product increments:

- `V1.1`: Investment Intent To Paper Trade
- `V1.11`: Investment Demo Release Closure (governed boundaries, full audit,
  replay, no-bypass enforcement)
- `V1.3`: Portfolio And Cash Impact Loop

Supporting platform epics:

- `P4`: Case, Evidence, And Replay Capsule
- `P8`: Build, Quality, Security, And Release Hygiene

## Why This Is A Milestone

This establishes the core product promise for the investing domain: a user can
express financial intent and Tickoni can turn it into a bounded, explainable,
replayable money decision before financial consequence.

It deserves milestone status because it closes the investing loop end to end:

- investment intent and paper trade construction
- cash, portfolio, obligation, approval, and drift impact

Payment proposals live in M5. M1 is the investing baseline everything else
builds on.

When M1 is complete, Tickoni is no longer only a runtime proof. It is a
consumer-money product that demonstrates safe investing action without live
execution.

## Completion Signal

M1 is complete when a user can run the roadmap demos for `V1.1` and `V1.3`
from deterministic fixtures and get replayable evidence for allowed, blocked,
resized, approval-required, evidence-required, and escalated investing flows.
