# M3: Institutional Valuation Engine

## Description

M3 proves the first forward-looking, assumption-driven analysis capability on the Tickoni surface:

```text
company financials -> Damodaran DCF + Monte Carlo -> proposal-grade valuation
```

The user supplies company financial data and policy inputs, the engine produces a
Damodaran-style discounted cash flow valuation with base/bull/bear scenarios,
sensitivity analysis, and native Monte Carlo uncertainty bands. Output is a
`valuation.analysis.propose` capability record with explicit scope, evidence, and
replay-stable computation — not a raw number.

## Included Epics

Platform and product increments:

- `V3.22`: Core Damodaran Engine — `tkval` tile, WACC, FCFF, Gordon Growth, exit-multiple cross-check, plugin architecture
- `V3.23`: Valuation Data Layer — ERP (FreeXL), EDGAR (Edgartools), XBRL (Arelle), market data collection, financial statement validation
- `V3.24`: Monte Carlo and Scenario Analysis — native Monte Carlo simulation, cross-check suite (reverse DCF, peer multiples, SOTP), sensitivity tables, methodology self-audit
- `V3.25`: Investment Conclusion and Governance — per-share value, verdict engine, `valuation.analysis.propose` capability envelope, audit trail, replay, demo closure

## Why This Is A Milestone

M1 established the investing demo loop (intent -> paper trade -> impact). M2 made
the harness runtime real. M3 extends Tickoni from governing known actions to
governing forward-looking, assumption-driven analysis with full uncertainty
modeling.

It deserves milestone status because it shifts what Tickoni does qualitatively:

- prior milestones governed actions after they were decided; M3 makes Tickoni a
  platform for decisions that are forward-looking and assumption-dependent
- Damodaran's academic discipline (explicit ERP, explicit beta, explicit term
  structure, explicit country risk, explicit scenario trees) makes assumptions
  auditable and replayable, which is a product differentiator over generic
  valuation tools
- the native Monte Carlo engine and Varanus integration bring institutional-grade
  numerical computation into the Tickoni runtime — no Python/R dependency, no
  external tool boundary
- valuation output enters the capability envelope model (`valuation.analysis.propose`),
  so it gets the same policy-gated, audit-ready, replay-stable treatment as
  trading or payment proposals

When M3 is complete, Tickoni can produce a proposal-grade valuation record from
raw financial data that is traceable to input assumptions, reproducible under
deterministic fixtures, and inspectable in CaseOps — all without an LLM, external
model provider, or live data feed.

## Completion Signal

M3 is complete when `just val-demo` runs the full pipeline (data ingestion ->
DCF engine -> Monte Carlo -> per-share value -> investment verdict -> capability
proposal), the native Monte Carlo engine produces base/bull/bear cases with
uncertainty bands from at least 10,000 iterations in under 30 seconds on a
single core, and the full valuation output — enterprise value range, cost-of-equity
breakdown, terminal value sensitivity, scenario probabilities, verdict with
upside and margin of safety, and a `valuation.analysis.propose` capability record
with evidence hashes — is replay-stable and inspectable in CaseOps.
