# M8: YouTube Research Monitor

## Description

M8 closes the research-intelligence gap by adding a governed YouTube monitoring
and summarization capability: a user subscribes their own channels, Tickoni
detects new videos, fetches metadata and captions, generates source-grounded
summaries through the model gateway, and surfaces those summaries as
audit-chained evidence in CaseOps. Every summary links back to a timestamped
source video, is replayable from a deterministic capsule, and never triggers
execution or stores full transcripts.

```text
user channels -> poll & summarize -> audit evidence -> CaseOps surface
```

## Included Epics

Product increments:

- `V8.1`: YouTube OAuth and Channel Read — authenticate user via YouTube Data API, read subscribed channels, present selectable list to user
- `V8.2`: Channel Monitoring Poll — periodic detection of new videos on user-selected channels, metadata fetch, dedupe against known videos
- `V8.3`: Caption Retrieval and Summary Generation — download available captions, generate source-grounded summary via `tkmodl` path, metadata-only fallback with disclaimer
- `V8.4`: Policy and Capability Definition — define `research_signal.youtube_ingest` capability in `tkpoly`, establish channel-scope constraints and summary-only boundaries
- `V8.5`: Audit Recording and Evidence Attachment — record ingestion events in `tkaudt`, attach evidence in `tkevid` when available, hash-chained audit trail
- `V8.6`: CaseOps Surface — display YouTube-sourced research evidence alongside other case evidence, with source links, timestamps, and "not investment advice" framing
- `V8.7`: Replay Support — deterministic replay of YouTube ingest events with summary substitution capsules, no external API calls during replay
- `V8.8`: Evidence, Demo, and Release Closure — fixtures, demo flow, quality gates, documentation

## Why This Is A Milestone

M1–M7 establish safe money decisions across investing, payments, crypto, and
operations, with a governed runtime, proof surfaces, and replay discipline. M8
adds the first external-source ingestion capability that feeds research evidence
into the investment proposal pipeline without introducing financial risk.

It deserves milestone status because it crosses a qualitative threshold in the
product's completeness:

- The investment workflow becomes end to end: research (YouTube) → analysis →
  proposal → approval → (paper) execution. No earlier milestone closes this
  loop.
- External-source ingestion is a new capability class. YouTube is the first
  source, but the audit, capability-envelope, replay, and model-governance
  patterns established here become the template for future sources (news feeds,
  podcast transcripts, regulatory filings).
- Every summary creates a traceable, replayable evidence record that CaseOps
  operators can verify. An operator reviewing a trade can see which YouTube
  videos informed the recommendation and trace each claim back to a timestamped
  source link. A generic scraper does not provide this auditability.

M7 established the approved execution sandbox for financial actions. M8 does not
perform financial actions — it produces evidence. The trust model is the same
(append-only audit, capability envelopes, replay substitution), but the
financial consequence surface is fundamentally different and demonstrates that
Tickoni's governance applies uniformly across both internal event streams and
external research sources.

## Completion Signal

A user can authenticate a YouTube account, select subscribed channels to monitor,
and verify that a new video triggers a summary that appears in CaseOps as
research evidence with source video URL, timestamp references, and "not
investment advice" framing. The same ingest event replays deterministically from
a fixture without calling the YouTube API, producing the identical summary and
audit record. A compliance operator can inspect the evidence trail and trace a
specific claim in a trading proposal back to a timestamped video segment in the
YouTube source material.
